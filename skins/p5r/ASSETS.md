## 换图步骤

1. 准备两张你有权使用的图：
   - **主背景**：建议 16:9 左右、偏暗、主体不要压在画面正中（中央区域会盖住
     欢迎语与输入框）
   - **设置背景**：方形，因为设置对话框接近 1:1
2. 覆盖 `assets/station.jpg` 与 `assets/settings.jpg`
3. 重新内嵌并构建：

```powershell
node tools/embed-assets.mjs
node tools/build.mjs
```

4. **刷新页面**（客户端代码改动必须刷新才生效）

## 调暗化程度

底图之上叠了一层线性渐变压暗，保证文字可读。位置在 `skins/p5r/decor.js`：

```js
'  background-image:',
'    linear-gradient(180deg, rgba(11,11,14,.32) 0%, rgba(11,11,14,.52) 100%),',
'    url(' + station + ');',
```

前两个数字是「顶部 32% / 底部 52% 黑」。图本身够暗就调小，字看不清就调大。
设置窗口的压暗是同一文件里的 `.62`。

## 站牌覆盖层

背景图里那块「悬吊発車標」上的滚动文字是**真 DOM**（静态图片动不了），
按量出来的几何盖在图片同位置，并跟着底图一起漂移。

换图后几何会失配，需要重新量。参数在 `skins/p5r/skin.js` 的 `BOARD`：

```js
var BOARD = {
  left: 69.4, top: 23.3,      // 牌子左上角（占「按 cover 铺满后的图片盒」的百分比）
  width: 8.2, height: 6.6,    // 牌子尺寸（同上，百分比）
  rotate: -7,                 // 倾角（度）
  topText: '4番線  DEEPSEEK HARNESS  ',                        // 上行小黄字
  bottomText: '電車が参ります。黄色い線の内側まで、お下がりください。  ',  // 下行大绿字
};
```

**量法**：按 `1822 / 1024` 的比例看原图，用百分比量出牌子的左上角与宽高。
原图是 1822×1024 时，牌子约占 `x 69.4%–77.6%`、`y 23.3%–29.9%`。

`decor.js` 里的 `.p5r-board-cover` 用 `calc(100vh * 1822 / 1024)` 保持与原图
同比例铺满，所以只要比例不变、换图后重新量百分比即可。**换不同比例的图，
这个 `1822 / 1024` 也要一起改。**

不想用站牌层？删掉 `skins/p5r/skin.js` 里的 `dom: { comic: decor.p5rBoard }` 一行，
再删 `decor.js` 里 `.p5r-board*` 那几段即可，配色不受影响。
